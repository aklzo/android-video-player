# 仕様書: Google Drive 動画プレイヤー

Google Drive 上の動画(.mp4)をサムネイル付き一覧から選んで再生する Android アプリ。

- リポジトリ: android-video-player
- パッケージ: com.aklzo.videoplayer
- minSdk 26 / targetSdk 34
- Kotlin + Jetpack Compose + Jetpack Media3 + Google Drive API

## 1. Google 認証

- Credential Manager + AuthorizationClient で Google アカウントにサインインし、
  `https://www.googleapis.com/auth/drive.readonly` スコープの OAuth アクセストークンを取得する。
- 初回起動時はサインイン(同意)画面を表示する。以降はサイレントに認証する。
- トークン失効時(API が 401 を返す等)は再サインインを促す UI を表示する。
- 書き込み系 API は使用しない(drive.readonly の範囲に限定)。

## 2. 対象フォルダ選択(複数)

- 初回サインイン後、Drive のフォルダをブラウズして動画フォルダを選択する画面を表示する。
- 対象フォルダは**複数選択でき、後から追加・削除できる**。
  - 設定画面に選択中フォルダの一覧と「フォルダを追加」「削除」の操作を設ける。
- 選択したフォルダ(ID・名前)のリストは永続化し、次回以降は選択不要。
- 一覧には全対象フォルダ配下の動画をマージして表示する(同一ファイルは重複させない)。
  フォルダパス表示は「対象フォルダ名/サブフォルダ…」の形式。

## 3. 一覧表示

- 選択フォルダ**配下(サブフォルダを再帰的に含む)**の `.mp4` を Drive API `files.list` で
  列挙して一覧表示する。動画と `.webp` はサブディレクトリ単位でひとまとまりに保存されている
  想定であり、そのまとまりより上位のフォルダを選択してもすべての動画が一覧に出る。
- 表示は YouTube のようなサムネイルグリッド。タップで再生する。
- 画面下にタブを表示し、「動画一覧」(対象フォルダ配下すべて)、「プレイリスト」、
  「保存済み」(キャッシュ保存が完了した動画のみ)を切り替えられる。
  保存済みタブ・プレイリストタブはローカルのメタデータから構築し、オフラインでも表示できる。

## 3.5 プレイリスト

- プレイリストを作成・削除できる(名前付き)。
- 動画一覧・保存済みタブのカードを**長押し**するとプレイリストへ追加できる
  (追加先の選択、または新規プレイリスト作成)。
- プレイリストタブに一覧(名前・件数)を表示し、タップで中身(追加順)を表示する。
- プレイリスト内の動画はタップで再生、長押しでプレイリストから削除できる。
- プレイリストの内容(動画のメタデータ)は Room に保存し、オフラインでも表示できる。
- サムネイル: 同名(拡張子違い)の `.webp` が**同じディレクトリ**にあればそれを表示する。
  - `.webp` はその場でダウンロードしてローカル(アプリ専用ストレージ)にキャッシュする。
  - `.webp` がない場合は Drive API の `thumbnailLink` をフォールバックとして使う。
- オフライン時や API 失敗時はエラー表示と再試行ボタンを出す。

## 4. 月グルーピングとタイトル表示

- ファイル名は先頭に `yyyyMMdd` 形式の日付 + アンダースコアを持つ(例: `20260315_タイトル.mp4`)。
- 正規表現 `^(\d{8})_` でパースし、日付として不正な値(13月・32日など)は弾く。
- 一覧は日付降順ソートし、**月ごと**(例: `2026/04`)にグルーピング表示する。
- パース不能なファイルは「日付不明」グループとして末尾に表示する。
- 一覧のタイトルは**日付プレフィックスと拡張子を除いて**表示する
  (例: `20260315_タイトル.mp4` → `タイトル`)。日付などのメタ情報は再生画面の概要欄に表示する。

## 5. 再生(ストリーミング+バックグラウンド保存)

- 一覧タップで即座にストリーミング再生を開始する(`files.get?alt=media`)。
- 再生と並行して、動画全体をバックグラウンドでアプリ専用ストレージ
  `files/video_cache/` に保存する(再生で受信したデータは共有され、二重取得しない)。
- 保存中は再生画面に進捗を表示する。
- 保存済み(キャッシュ有効)の動画はオフラインでも即再生できる。
- 一覧上にキャッシュ済みインジケータを表示する。

## 6. 再生画面

- YouTube のようなレイアウト: 上部に動画プレイヤー(16:9)、下部に概要欄を表示する。
- 概要欄にはタイトル(日付・拡張子なし)、日付、フォルダパス(選択フォルダからの相対)、
  ファイル名、サイズ、保存状態(保存済み/保存中◯%/未保存)を表示する。
- 再生/一時停止、シークバー対応。プレイヤーの全画面ボタンで全画面(概要欄と
  システムバーを隠す)に切り替えられる。全画面中の「戻る」は全画面解除。

## 7. バックグラウンド再生

- アプリを離れても・画面をオフにしても音声再生が継続する。
- `MediaSessionService` を使い、通知の再生コントロール(再生/一時停止/停止)と
  ロック画面表示に対応する。

## 8. キャッシュ管理(LRU)

- キャッシュ合計が容量上限を超えたら、最終再生日時が古いものから削除する。
  - 上限デフォルト 10GB。設定画面で 5GB / 10GB / 20GB / 50GB から変更可。
- 最終再生から 30 日(設定で 7日 / 30日 / 90日 / 無期限から変更可)経過したファイルは
  起動時に削除する。
- 再生中のファイルは削除対象外。
- 設定画面に現在のキャッシュ使用量表示と手動全削除ボタンを設ける。
- キャッシュメタデータ(fileId、最終再生日時、サイズ)は Room で管理する。

## 9. 通信量への配慮

- 動画ダウンロードは Wi-Fi 接続時のみ許可がデフォルト。設定でモバイル回線も許可できる。

## 10. 設定画面(まとめ)

- 対象フォルダの変更
- キャッシュ容量上限(5/10/20/50GB)
- キャッシュ保持期間(7日/30日/90日/無期限)
- モバイル回線でのダウンロード許可 ON/OFF
- キャッシュ使用量表示・全削除ボタン
